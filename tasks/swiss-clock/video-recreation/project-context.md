# Контекст EOSDO1.0

Исходное состояние 2026-10-28: ветка `main`, commit `53a018f`, чистое дерево, origin `GnomikNaPony/EOSDO1.0`. В репозитории был только README; команд, приложения, тестов и CI не было. Осмотрено все исходное дерево. Разрешение создать сайт и отправить в этот Git дано пользователем.

Цель: интерактивное визуальное воспроизведение системы из видео. Источник истины — приложенная запись 337.92 с, 478×270, и пояснения говорящего. Разобраны кадры на протяжении всей записи и локально распознанная звуковая дорожка. Мелкий текст и реальные реквизиты не восстанавливаются; используются вымышленные записи.

Термины: документ — регистрационная карточка; задача — действие пользователя над документом; поручение — исполнение с исполнителями и сроком; дело — позиция номенклатуры; очередь согласования — последовательная группа согласующих; виза — локальный результат рассмотрения. Юридически значимые процессы, подпись и действительные организационные правила неизвестны и в прототип не входят.

Архитектура: нативный DOM/ES-модули и CSS. Вход `index.html` → `src/app.js`; демонстрационные записи/фильтрация/сериализация `src/data.js`; иконки `src/icons.js`; стили `src/styles.css`. Состояние → localStorage одного браузера → повторная отрисовка. Данные из форм и хранилища экранируются перед HTML-вставкой. Внешних запросов приложения нет. Синхронизация между пользователями не предусмотрена.

Среда: macOS arm64, Node 26.0.0, npm 11.12.1. Vite 7.3.7 — разработка/сборка; Playwright 1.64.0 — Chromium. Зависимости фиксируются lock-файлом. Команды и границы проверок — README, результаты — completion.md. Защита ветки/CI не меняются.
