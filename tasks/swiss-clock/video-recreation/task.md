# video-recreation: воспроизвести ЕОСДО по видео

Статус: реализация.

## Цель и основания

Пользователь просит максимально похожий сайт на основе видео и отправку в Git. В границах: внешний вид и наблюдаемые локальные сценарии, узкий экран, демонстрационные данные, инструкции, проверки, commit/push в существующий origin. За границами: реальная ЕОСДО, подпись, серверные процессы, деплой хостинга. Риск обычный: обратимый прототип с вымышленными данными, без реальных отправок и доступа.

## Исходное состояние

База `53a018f`, чистая `main`, README без приложения. Исходных проверок нет. Контекст: [project-context.md](project-context.md). Источник: видео пользователя 337.92 с; низкое разрешение не позволяет подтвердить буквальное совпадение мелкого текста.

## Область влияния

Событие → нормализованный фильтр/валидированная форма → демозаписи → таблица/карточка → localStorage. Карточка имеет стабильный ID в hash. Тексты экранируются; CSV защищается от формул. Файлы — демонстрационные UTF-8 документы. Даты ISO, отображение DD.MM.YYYY; просрочка относительно демоснимка 2026-10-28. Согласование локальное, без отправок. Восстановление: сброс демоданных. Миграций нет.

## Решение и проверки

HTML/JS/CSS; Vite для сборки/сервера, Playwright для настоящих UI-сценариев. Обязательны unit, production build, desktop/mobile E2E, визуальный осмотр, два отдельных прохода саморевью diff. Независимое ревью обычным риском не требуется и не заявляется. Внешние настройки и хостинг не меняются.

## Неопределенность

Факт: структура и действия видны и озвучены. Неизвестно: мелкие подписи, оригинальный CSS и скрытые серверные правила. Решение: повторить видимые структуры/переходы, использовать демореквизиты; не заявлять production-интеграцию или пиксельное совпадение.
